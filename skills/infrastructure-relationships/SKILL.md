---
name: infrastructure-relationships
description: Compare named public websites and historical infrastructure observations while testing unrelated-ownership explanations.
---

Inputs: case_id, named public domains and `infrastructure_evidence_ids`. Collect
with existing `resolve_dns`, `inspect_tls_certificate`, `public_rdap_snapshot`,
`public_site_manifest`, `public_site_identity_map`, snapshot tools and supported
CT/archive connectors. Preserve results as dated evidence.

Run `investigation_workflow_run` profile `infrastructure-relationships`. Review
shared tracking identifiers, assets, templates, redirects and dated DNS/registration
changes. Record only the observed typed relation; retain evidence, validity dates,
contradictions and ordinary provider/template explanations in each graph edge.

Expected outputs: evidence-backed temporal technical graph and investigative
leads. Shared hosting, scripts, certificates or analytics do not prove common
ownership or malicious coordination. Unavailable history is incomplete coverage.
Verify hashes and source versions; never call endpoints discovered inside scripts.
